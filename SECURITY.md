# Security policy

Please report security problems privately, not in a public issue: use GitHub's **Report a vulnerability** button on
the repository's Security tab. You'll get an answer within a week. Fixes are released as soon as they are ready, and
reporters are credited unless they prefer not to be.

In scope: Tidegate's own code (the filter, web pages, digest and scheduler) and its default configuration. Problems in
Postfix, Rspamd, ClamAV, Valkey or Unbound themselves should go to those projects; tell us too if Tidegate's defaults
make them worse.
