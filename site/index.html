Tidegate

A free, open-source email security gateway you run yourself. It stops spam, viruses, phishing and impostors before they reach your inbox.

What it does

Filters every message

Rspamd checks for spam and checks SPF, DKIM and DMARC. ClamAV scans attachments, and phishing feeds check every link.

Quarantine and daily digest

Held spam shows up in one email per person each day. Each message has a Release button, so people fix their own false positives.

Impostor warnings

It catches look-alike domains, your own domain faked, and your CEO's name on mail from outside. Clear cases are held, and doubtful ones get a warning.

Allow, block and log

Allow and block lists can't be fooled by a faked address. A searchable log shows every message and why it was handled as it was.

How it works

Tidegate sits in front of your mail server: Microsoft 365, Google Workspace, Exchange or Postfix. It is built from proven open-source parts. Postfix receives the mail, Rspamd scores it, ClamAV scans it, and a small Python service decides what to do and runs the quarantine pages. It's one Docker Compose file, and it needs about 2.5 GB of memory.

git clone https://github.com/hapnesbitt/tidegate.git
cd tidegate
cp .env.example .env
cp config/tidegate.toml.example config/tidegate.toml
docker compose up -d

Already running Postfix? Keep it as the front door and add Tidegate behind it. The guide covers the three changes, a fail-open path and a rollback.

Status

Version 0.1 is the first release. It is tested end to end in a lab and runs in front of real mail. Next on the list is a DMARC report dashboard, then link checks at click time.
